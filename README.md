# FC Boot Protector

**FC Boot Protector** is a RuneLite plugin designed to prevent misclicks when moderating or hanging out in Friends Chats. It automatically filters out the "Kick" menu option unless specific criteria (like holding a modifier key) are met.

---

## 🚀Features

* **Kick Option Removal:** Automatically hides any context menu option containing "Kick" while inside a Friends Chat.
* **Shift-Key Bypass:** Optionally hold down the **Shift** key while right-clicking to reveal the "Kick" option when you actually intend to kick someone.

---

## ⚙️ Configuration Settings

| Setting | Type | Default | Description |
| --- | --- | --- | --- |
| **Protect Friends Chat Kicks** | Toggle | `Enabled` | Enables or disables the removal of the "Kick" option in Friends Chat context menus. |
| **Allow Kick with Shift** | Toggle | `Disabled` | When enabled, holding down the **Shift** key allows the "Kick" option to appear in right-click menus. |

---

## 📛 Installation

1. Open RuneLite.
2. Open the **Plugin Hub** panel on the right sidebar.
3. Search for **FC Boot Protector**.
4. Click **Install**.
